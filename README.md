# Claude 静默模式 — 记录 · 点击才答（v0.2）

装在 **claude.ai 网页版**上的 Chrome / Edge 扩展。

- **静默记录**：悬浮按钮开启后，你说的话（语音停顿自动分句）进扩展侧栏，**不发给 Claude**；点某条时才把「该条+上下文+指令」拼好塞进 Claude 输入框并发送。
- **全局快捷键**：在**任意标签页**按快捷键，把剪贴板文字 / 当前标签页截图，发到你**指定的 Claude 标签页**——不用切回 claude.ai。
- 不碰 API、不用 key，用的还是你自己的 claude.ai。

## 安装

1. `chrome://extensions` → 开「开发者模式」→「加载已解压的扩展程序」→ 选本文件夹。
2. 打开/刷新 https://claude.ai ，右下角出现 ✦ 按钮。
3. （可选）去 `chrome://extensions/shortcuts` 确认或修改两个快捷键。

## 指定目标 Claude 标签页（新）

侧栏「设置」里有「目标 Claude 标签页」：

- 点「把此标签页设为目标」→ 把当前这个 claude.ai 页设为接收目标；
- 或从列表里点任一个已打开的 claude.ai 页；
- ↻ 刷新列表。

全局快捷键发送的内容都会进这个目标页。**多显示器没问题**：只要目标页和会议页在**同一个 Chrome**（同一用户资料）里，放哪块屏、哪个桌面都行。

## 两个全局快捷键

- **Ctrl/⌘+Shift+U**：把当前剪贴板文字发到目标 Claude 页并发送。
- **Ctrl/⌘+Shift+Y**：截「当前活动标签页」（你鼠标所在那个）的可见区，发到目标 Claude 页。

## 静默记录用法

1. 右下角 ✦ 开侧栏 → 点 🎙 开口，**停顿处自动分成一条条**（也可手动输入，回车存一条）。
2. 点某一条 → 拼好上下文丢进 **当前** claude.ai 页作答。
3. 导出：设置里可导出 `.txt` / `.md` / `.json`。

## 必须知道的边界

1. **文字投递是全自动、稳的；截图「自动进输入框」是尽力而为**。截图会先写进系统剪贴板并切到目标页，同时尝试模拟粘贴进输入框。若某次没自动进去，你在已切到的 Claude 页手动按一次 Cmd/Ctrl+V 即可——图已在剪贴板，不丢。
2. **依赖 claude.ai 页面结构**：填输入框/点发送靠识别页面元素，claude.ai 改版可能导致失效，届时更新选择器即可。
3. 全局快捷键与截图由后台协调；首次触发时浏览器可能就权限弹一次确认。

## 结构

```
manifest.json    MV3：内容脚本 + 后台 + 全局命令 + 权限
content.js       claude.ai 上的静默侧栏（记录/语音/点击发送/目标选择 UI）
background.js    后台：目标标签页管理、全局快捷键、截图、跨页投递
offscreen.html/js 读剪贴板文字 / 写图片到剪贴板（后台无 DOM，借它代做）
```

## 隐私

记录只存本机浏览器（chrome.storage.local，约 10MB，可存约三百万字）。语音用浏览器自带识别。发送经由你自己的 claude.ai 会话，和手打无异。
